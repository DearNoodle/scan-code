# Code Label Tool

Type a payload, generate a 1D or 2D code, and scan it off the screen.

[Open the app](https://dearnoodle.github.io/scan-code/index.html)

## What it does

- Generate **Code 39**, **Code 128**, **QR**, **PDF417**, and **Data Matrix**
- Full-screen preview for scanning from a device
- Draft session saved in the browser
- Named label sets you can save, load, and delete locally
